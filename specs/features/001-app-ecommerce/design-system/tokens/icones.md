# Ícones

> Fonte: [Ícones](https://zeroheight.com/5979403e1/p/418662-icones) no Zeroheight. Extraído em 2026-07-29.

O Alquimia Mobile utiliza a biblioteca **Material Symbols (New)**, desenvolvida pelo Google — ampla variedade de ícones consistentes, acessíveis e escaláveis, para uma experiência visual padronizada em todos os produtos.

## Configuração padrão (obrigatória para todos os ícones)

| Propriedade | Valor |
|---|---|
| Estilo | Rounded |
| Peso (Weight) | 300 |
| Preenchimento (Fill) | Off (contorno, não preenchido) |
| Grade | Normal (0) |
| Tamanho óptico (Optical size) | 24dp |
| Fonte | Material Symbols |

Essas configurações garantem uma aparência leve, moderna e alinhada com os demais componentes visuais do sistema.

## Como encontrar um ícone

1. Acesse [Google Fonts Icons](https://fonts.google.com/icons?icon.style=Rounded).
2. No painel lateral, configure: Style = Rounded, Weight = 300, Fill = Off, Grade = 0, Optical size = 24dp.
3. Use a busca para encontrar o ícone pelo nome desejado.
